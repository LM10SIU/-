# 星程长沙 - 全国景点打卡系统

> 以长沙为起点，面向全国的综合性旅游服务平台。集景点查询、打卡分享、评价互动、行程规划、酒店餐厅推荐、AI 智能助手于一体，打造一站式的“食住行游”体验。

---

## ✨ 核心功能

| 模块 | 功能亮点 |
|------|----------|
| 🏞️ **景点管理** | 全国景点浏览、详情查看、多维度筛选与搜索 |
| 📍 **地图导航** | Leaflet 地图展示、高德路线规划、多类型地点可视化 |
| 📸 **打卡分享** | 打卡记录、图片上传、点赞互动 |
| ⭐ **评价系统** | 星级评分、评价发布、点赞与回复 |
| ❤️ **收藏管理** | 景点/酒店/餐厅收藏与取消收藏 |
| 🗺️ **行程规划** | 多日行程创建，景点/酒店/餐厅灵活添加，自动路线优化 |
| 🏨 **酒店预订** | 酒店信息浏览、评价、加入行程 |
| 🍜 **餐厅美食** | 餐厅搜索、菜系筛选、特色菜品展示 |
| 💎 **宝藏景点** | 用户 UGC 提交、管理员审核、社区互动 |
| 🤖 **AI 助手** | 基于智谱 AI 的智能问答，结合数据库真实数据推荐 |
| 📊 **数据可视化** | ECharts 图表、数据大屏，多维度展示平台运营数据 |

---

## 🛠 技术栈

### 前端
- **Vue 3** + Composition API
- **Vue Router 4** + **Pinia** 状态管理
- **Element Plus** UI 组件库
- **Leaflet** 地图库
- **Axios** HTTP 客户端

### 后端
- **Spring Boot 3.x**
- **Spring Security** + **JWT** 认证授权
- **MyBatis** 持久层
- **MySQL 8.0** 数据库
- **HikariCP** 连接池
- **智谱 AI API** 集成
